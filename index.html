銅層數調整說明（1–512 層，輸入完成後自動套用）

可輸入 1–512 個銅層，例如 16、24、32；奇數也可。增層保留既有資料並在底部銅層內側插入銅層＋介質，減層須確認。總厚度會隨之改變，需要時再按「均分」。一次產生上限 512，以避免誤輸入大量層使表格與預覽停頓；匯入既有 XML 不受此產生上限截斷。

📖 如何將 XML 疊層匯入 Ansys SIwave

本工具依 Ansys 公開 Stackup XML 範例輸出材質與層設定；請在你的 SIwave 版本中核對匯入結果。請依照以下步驟匯入：

  1. 在 Ansys SIwave 中開啟您的 PCB 專案 (或已導入的 layout 檔)。
  2. 於上方選單點選 Layout → Layer Stackup... 開啟疊層設定視窗。
  3. 在疊層視窗下方或工具列點選 Import... 按鈕。
  4. 選擇由此工具匯出的 .xml 檔案即可一鍵載入所有導體層、介質層、厚度及材質參數！

🧭 Ansys SIwave 完整模擬流程 SOP 與必備檢查清單

在 Ansys SIwave 模擬中，要獲得準確的 **SI (訊號完整性)**、**PI (電源完整性)**、**DC IR-Drop (直流壓降)** 或 **EMI 輻射** 結果，請遵循以下 6 個標準作業步驟：

步驟 1：疊層與材質設定 (Layer Stackup & Materials) ✓ 本工具已直接支援

操作路徑：Layout → Layer Stackup... → Import XML

  • 正確定義各金屬銅箔層厚度（1 oz ~ 0.035mm / 0.5 oz ~ 0.018mm）。
  • 指派板材介電常數（Dk）與介質損耗（Df）（如 FR4, Megtron6, Rogers）。
  • 設定頂層/底層綠漆防焊層（Solder Mask, Dk=3.5），避免表面微帶線阻抗計算失真。
步驟 2：Net 網路分類與 DC 電壓指派 (Net Classification) 必做關鍵設定

操作路徑：Layout → Classify Nets... 或於左側 Nets 樹狀圖右鍵分類

  • Signal Nets：指定一般高速/低速訊號線。
  • Power Nets：指定電源網路（如 +12V, +3.3V, VDD_DDR），並務必填入其工作 DC 電壓。
  • Ground Nets：指定接地網路（如 GND, AGND），預設電壓為 0V。
  • (若未設定正確電壓，DC IR-Drop 壓降與去耦電容分析將無法進行)。
步驟 3：元件電氣特性與模型指派 (Component Assignment) 模型精準度核心

操作路徑：Components → Assign RLC... / Assign Device Model...

  • 去耦電容 (Decoupling Caps)：指派真實 RLC 數值，或掛載電容廠商提供的 .s2p S 參數模型（包含真實 ESR/ESL 寄生特徵）。
  • 串聯阻抗/磁珠/跳線：阻抗匹配電阻（如 22Ω）或 0Ω 電阻必須賦予正確值，避免訊號走線在該處被視為斷路。
  • VRM 源端與 Sink 負載 (针对 PI/DC)：指定電源供應點（Voltage Source）及各 IC Pin 的吃載電流（Current Load）。
步驟 4：版圖驗證與銅箔粗糙度 (Verify Layout & Roughness) 除錯與高頻必檢

操作路徑：Tools → Verify Layout... & Layer Stackup → Surface Roughness

  • DRC 幾何驗證：執行檢查是否有未預期的短路（Shorts）、意外斷線（Opens）或懸空未接銅箔（Floating Islands）。
  • 過孔反焊盤 (Via Anti-pad)：確認過孔穿越內層平面時是否具備正確的 Clearance 隔離。
  • 銅箔粗糙度 (Surface Roughness)：高速訊號（> 5 Gbps）務必開啟 Huray 或 Hammerstad 模型，否則高頻趨膚效應導體損耗會被嚴重低估！
步驟 5：埠與激勵源設定 (Ports & Probes Definition) S 參數與迴流關鍵

操作路徑：Simulation → Generate Circuit Ports...

  • 在發射端（Driver）與接收端（Receiver）建立 Circuit Ports。
  • 迴流接地參考（Reference GND）：嚴格確認 Port 的負端是否接在最近且連續的 GND 參考面上，避免引起假性迴流電感。
  • BGA Pin Grouping：若晶片底座有密集並聯的 GND/Power pins，使用 Pin Group 結合成單一 Port，大幅節省運算資源。
步驟 6：配置並執行模擬求解器 (Simulation Solver Setup) 依目的選取求解器
模擬目標 推薦求解器 Setup 關鍵設定重點
DC IR 壓降 / 載流過熱 Compute DC IR Drop 勾選計算過孔/走線電流密度分佈、設定工作溫度 (如 25°C 或 85°C)
S 參數 / PDN 阻抗 Z11 Compute SYZ Parameters 設定頻率範圍 (如 100kHz ~ 10GHz)、Decade 取樣分佈、收斂精度

EMI / EMC 輻射預估 Compute Near/Far Field 設定法規量測距離 (如 3m / 10m 球面場型)
