SIwave 的欄位，依照使用順序排好了

v2.8 的層表依照片顯示 Color、Name、Type、Thickness、Material、Conductivity、Dielectric Fill、Relative Permittivity、Loss Tangent。原來的「基本編輯」仍可切換使用。

選一種材質，就帶出它的電氣數值

例如選 copper，導電率顯示 5.80E+7。若材質沒有定義介電常數，就顯示「—」，避免把未知值假裝成 0。需要自訂數值時，新增材質後，再於那一層選用。

畫面與資料各自怎麼保存？

Thickness 決定層厚；Color 改變本工具的色標。金屬層可選 Dielectric Fill，介質層則不適用。匯出 XML 會保存材質、厚度與填充；顏色與角色放在 XML 註解中，供本工具再次匯入時還原，不能保證 SIwave 也套用顏色。

完整欄位在小螢幕中需要左右捲動；整個頁面不必橫向捲動。資料留在目前瀏覽器，重新整理或換裝置前，請先匯出 XML。頁面底部可下載獨立 HTML，離線開啟。

確認過什麼，還有哪些限制？

瀏覽器檢查涵蓋原有功能、五種畫面寬度、200% 放大、新欄位與 XML 往返。匯出依照 Ansys 公開格式；尚未在使用者安裝的 SIwave 版本實測。匯入遇到尚未支援的進階設定會取消，避免悄悄遺失資料。
